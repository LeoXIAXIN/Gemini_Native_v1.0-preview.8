# Gemini Native：G1 真机快速指南

> 真机功能仍属实验阶段。首次测试必须使用**已受力的安全支撑架**，清空机器人周围区域，并由操作员全程掌握实体遥控器和物理急停。网页“停止控制”不是急停。

操作前请完整阅读 [G1 手柄说明](README_G1_REMOTE.md) 和机器人原厂安全说明。不同固件的行为可能不同，以现场设备和原厂说明为准。

## 1. 先验证仿真

1. 确认动捕设备、骨架输出和机器人模型与现场设备匹配。
2. 在控制台选择“仅仿真”，检查动作方向、站姿和运行状态。
3. 仿真不正常时停止，不要继续真机测试。

## 2. 准备现场

1. 将机器人置于安全支撑架内，确认支架已受力。
2. Windows 有线网卡连接 G1。在控制台的“Unitree 网络接口”填写**本机有线网卡的 IPv4 地址**。
3. 先不要启动脚本或网页真机任务。按原厂流程使机器人进入阻尼/零力矩状态，完全松开手柄按键，再用 `L2 + R2` 进入 Develop。
4. 确认机器人已进入 Develop 后，才双击 `03_Check_Unitree_LowState.cmd`，完成 60 秒只读检查。只有检查通过才能继续；失败时停止测试并排查现场问题。

## 3. 启动实验

1. 如需先验证连接，在网页选择“仅真机”并勾选“真机调试模式”；检查完成后停止该任务。
2. 保持机器人稳定、摇杆回中、实体遥控器和物理急停在手。若机器人已退出 Develop，须在网页真机任务停止后重新按原厂流程进入。
3. 取消“真机调试模式”，启动真机任务；所有环境检查必须通过。
4. 按界面提示输入 `ARM G1`。等待程序提示准备完成，完全松开手柄按键，再按提示使用 `START` 授权。
5. 等待稳定站立及等待 `A` 的提示出现后，才可接入实时动捕。无需在界面选择 4010/5010 电机版本。

## 4. 运行与停止

- `A`：接入实时动捕；`B`：返回站立；`SELECT`：正常退出。按键前先松开其他按键，并遵循界面提示。
- 正常退出时，先按 `SELECT`，确认程序提示控制已关闭，再停止网页任务。
- 发生抖动、倾倒、碰撞风险、动作突变或通信异常时，**立即使用实体急停或原厂安全功能**，不要等待网页或软件按钮。
- 动捕或机器人状态丢失后，不要直接重启真机输出；先重新完成仿真与现场检查。
