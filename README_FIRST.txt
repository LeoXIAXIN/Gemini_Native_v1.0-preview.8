Gemini Native v1.0 Preview
==================================

本文件适用于获授权的完整发布包。公开源码仓库不包含运行所需的全部组件、模型和客户授权，不能仅凭源码直接启动。

系统：Windows 10/11 x64。

首次使用：
1. 将完整发布包解压到本机目录，不要直接从 ZIP、网络共享或同步盘运行。
2. 使用包内的授权安装程序导入获授权的许可证。
3. 启动动捕，确认动捕设备和骨架输出正常。
4. 启动 Gemini Native，先运行动作预览和仿真。
5. 只有完成设备与安全检查后，才按真机指南开展实验。

真机控制属于实验功能。必须使用安全支撑架、实体遥控器和物理急停；网页停止按钮不是急停。

客户许可证及设备资料仅保存在获授权的本机部署环境，不要提交到公开仓库。
