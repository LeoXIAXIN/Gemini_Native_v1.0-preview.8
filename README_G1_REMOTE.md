# Gemini Native：G1 手柄操作

> 真机操作仅供完成设备与安全验收的人员使用。机器人必须位于已受力安全支撑架内，周围无人、无障碍物；操作员须全程掌握实体遥控器和物理急停。网页停止、`SELECT` 和软件保护退出都不是物理急停。

## 启动前

先不要启动网页真机任务。按原厂流程让机器人进入阻尼/零力矩状态，完全松开手柄按键，再按 `L2 + R2` 进入**机器人 Develop 模式**。不同固件的状态提示可能不同，请结合原厂说明确认。

网页“真机调试模式”用于先检查连接，不会让机器人进入 Develop；只有先完成手柄操作，才启动网页任务。正式真机实验前还须通过 60 秒只读验收。

## 授权与接管

1. 确认机器人稳定、摇杆回中，操作员握住遥控器并可立即触发物理急停。
2. 在网页取消“真机调试模式”，启动任务并等待环境检查通过。
3. 按界面提示输入 `ARM G1`，等待程序显示 `Develop ready for START`。
4. 完全松开手柄上的所有按键；看到 `START gate armed` 后，只按 `START`，直到出现 `START authorization accepted`，随后松开。
5. 等待程序显示稳定站立并提示可以按 `A`。在此之前不要接入动捕或移动机器人。

## 运行中的按键

普通操作键应在肩键全部松开的情况下单独按下，再松开：

| 按键 | 用途 |
|---|---|
| `A` | 稳定站立后接入实时动捕 |
| `B` | 返回站立 |
| `SELECT` | 正常、有序退出 |
| `L2 + B` | 按现场提示执行软件保护退出；不是物理急停 |

正常结束时，先按 `SELECT`，保持支架受力，确认程序提示控制已关闭，然后才停止网页任务；恢复原厂控制应遵循该设备的原厂流程。

出现抖动、倾倒、碰撞风险、动作突变或失控迹象时，**立即使用实体急停或原厂安全功能**。动捕或机器人状态中断后，停止实验并重新完成现场检查，不要直接重试。
